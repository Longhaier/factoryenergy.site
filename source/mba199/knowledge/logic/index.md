# 逻辑题型与解题方法

## 考试概况

逻辑部分共 **30 题，每题 2 分，共 60 分**，分为三大类：

| 题型 | 题量 | 特点 |
|------|------|------|
| **形式逻辑** | 8-10 题 | 有固定公式，可快速秒杀 |
| **论证逻辑** | 12-14 题 | 最易失分，占比最大 |
| **综合推理** | 6-8 题 | 最耗时，需找突破口 |

**建议时间分配**：形式逻辑 15 分钟 → 论证逻辑 25 分钟 → 综合推理 15 分钟，卡壳即跳。

---

## 第一部分：形式逻辑

形式逻辑有固定公式，像做数学题一样推理，不要凭感觉。

### 一、直言判断

| 类型 | 形式 |
|------|------|
| 全称肯定 | 所有 S 是 P |
| 全称否定 | 所有 S 不是 P |
| 特称肯定 | 有的 S 是 P |
| 特称否定 | 有的 S 不是 P |

**对当方阵关系**：
- **矛盾**（必一真一假）：所有是 ↔ 有的不是；所有不是 ↔ 有的是
- **上反对**（至少一假）：所有是 ↔ 所有不是
- **下反对**（至少一真）：有的是 ↔ 有的不是
- **包含**：所有是 → 有的是；所有不是 → 有的不是

**换位规则**：
- 所有 S 是 P → 有的 P 是 S
- 所有 S 不是 P ↔ 所有 P 不是 S
- 有的 S 是 P ↔ 有的 P 是 S

### 二、复合判断

| 逻辑词 | 逻辑形式 | 等价表达 |
|--------|---------|---------|
| 如果 P，那么 Q | P → Q | 非Q → 非P |
| 只有 P，才 Q | Q → P | 非P → 非Q |
| 当且仅当 P，则 Q | P ↔ Q | 双向推出 |

**假言推理规则（务必背熟）**：
```
P → Q
肯前必肯后：P 成立 → Q 成立
否后必否前：非Q 成立 → 非P 成立
否前不一定否后，肯后不一定肯前（不能推出）
```

**核心公式："或变推"**：
> P ∨ Q 等价于 非P → Q 等价于 非Q → P

**负判断（矛盾）**：
| 原命题 | 矛盾 |
|--------|------|
| P → Q | P 且 非Q |
| P 或 Q | 非P 且 非Q |
| P 且 Q | 非P 或 非Q |
| 所有 S 是 P | 有的 S 不是 P |

## 第二部分：论证逻辑

论证逻辑考的是**理解论证结构**和**识别推理漏洞**，是得分关键。

### 论证结构分析的必杀技

任何论证都由三部分构成：
> **论据**（因为）→ **论证关系**（推理）→ **结论**（所以）

**快速定位**：
- "因此""所以""由此可见"后面是 **结论**
- "因为""由于""依据"后面是 **论据**

### 削弱题

**目标**：让结论变得不可靠。

**削弱力度排序**（从强到弱）：
> 割裂论证关系 > 削弱结论 > 削弱前提 > 针对背景信息

**六种削弱方式**：

| 方式 | 说明 | 示例 |
|------|------|------|
| ① 割裂因果 | 直接说因果关系不成立 | 不是因为运动所以健康 |
| ② 因果倒置 | 结果导致了原因 | 是健康才运动，而非运动才健康 |
| ③ 他因同果 | 其他原因也能导致结果 | 瘦是因为节食，不是跑步 |
| ④ 有因无果 | 有原因但没出现结果 | 跑了但没瘦 |
| ⑤ 有果无因 | 没原因也出现了结果 | 没跑也瘦了 |
| ⑥ 矛盾削弱 | 用形式逻辑找 P→Q 的矛盾 | 找 P 且非Q |

**六类干扰项（记住它们，快速排除）**：

1. **偷换概念** — 选项核心词和题干不同
2. **过度绝对** — 出现"必然""一定""所有"等绝对化词
3. **诉诸他者** — "专家说""多数人认为"
4. **扩大范围** — 超出题干主体/时间/场景
5. **无关因果** — 只并列提到因果双方，没建立关系
6. **反向无关** — 方向完全反了（削弱题给加强项）

### 加强题

**目标**：让结论更可信。

**加强力度排序**：
> 搭桥（建立联系）> 无他因 > 有因有果/无因无果 > 加强前提 > 加强结论

**四种加强方式**：

| 方式 | 说明 |
|------|------|
| ① 搭桥 | 在论据和结论之间建立直接联系 |
| ② 无他因 | 排除导致结果的其他原因 |
| ③ 无因无果 | 没原因 → 没结果（反向证明） |
| ④ 有因有果 | 再次确认因→果关系 |

### 假设题

**方法：否定代入法**——把选项否定后代入题干，如果论证不成立，就是正确答案。

**常见类型**：
- **搭桥假设**：论据和结论之间有跳跃概念
- **因果假设**：因果不倒置、无他因、方法可行
- **差比假设**：比较对象其他方面的条件相同

### 结论题

**原则**：
- 紧扣题干，不能添加新信息
- 优先选"直接能从原文推出的"
- 警惕过度推理和偷换概念

## 第三部分：综合推理

综合推理耗时最多，学会**找突破口**是关键。

### 通用解题步骤

```
第一步：看问题类型（确定信息还是不确定信息）
第二步：读题干，找确定信息
第三步：用重复元素搭桥
第四步：列表法/画图法辅助
第五步：排除法快速淘汰错误选项
```

### 真话假话题

**解题流程**：
1. 符号化（把文字变成逻辑符号）
2. 找关系：矛盾 > 反对 > 包含
3. 锁定真假范围
4. 代入剩余条件推理

**常考矛盾关系**：
- P 与 非P
- P→Q 与 P且非Q
- P或Q 与 非P且非Q
- 所有是 与 有的不是

### 对应题

- **两类对应**：画表格，√×标注
- **三类及以上**：从确定信息出发，排除法
- **分组题**：注意边界条件（N个元素同组占N个位置）

## 第四部分：实战技巧汇总

### 解题三原则

| 原则 | 说明 |
|------|------|
| **同一律** | 优先选重复题干核心概念的选项 |
| **态度原则** | 题干是什么态度，选项就什么态度 |
| **结构一致** | 题干是"推"，选项不能是"且/或" |

### 否定代入法（验证假设题）

> 把选项否定后代入题干，如果论证被破坏，该选项就是正确答案。

### 时间策略

| 题型 | 建议时间 | 策略 |
|------|---------|------|
| 形式逻辑 | 15-18 分钟 | 公式秒杀，不要犹豫 |
| 论证逻辑 | 20-25 分钟 | 先削弱加强，再假设结论 |
| 综合推理 | 10-15 分钟 | 2分钟没思路就跳 |

---

## 学习建议

1. **形式逻辑靠公式**：先把"→"符号化练熟，每天做5道形式逻辑
2. **论证逻辑靠干扰项**：不要只看正确选项，更要分析错误选项为什么错
3. **综合推理靠速度**：每天做2道综合推理，控制每题3分钟内
4. **先类型后综合**：先分题型练→再做混合套题
5. **错题本要分类**：记录错题时标注"形式/论证/综合"类型

→ 学完方法后进入 [逻辑练习](/practice/mba199/logic/) 实战
