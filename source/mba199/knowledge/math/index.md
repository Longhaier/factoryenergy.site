## 一、算术

### 核心概念

| 概念 | 说明 |
|------|------|
| **质数** | 大于1，只能被1和自身整除：2,3,5,7,11,13… |
| **合数** | 大于1的非质数：4,6,8,9,10… |
| **互质** | 两个数的公因数只有1（如8和9） |
| **奇数/偶数** | 能被2整除为偶数，否则为奇数 |

### 奇偶数运算规律

| 运算 | 结果 |
|------|------|
| 奇数 ± 奇数 | 偶数 |
| 偶数 ± 偶数 | 偶数 |
| 奇数 ± 偶数 | 奇数 |
| 奇数 × 奇数 | 奇数 |
| 偶数 × 任何数 | 偶数 |

### 绝对值

- \\(|x| < a \iff -a < x < a \\ (a>0)\\)
- \\(|x| > a \iff x < -a \text{ 或 } x > a \\ (a>0)\\)
- 三角不等式：\\(||a|-|b|| \leq |a \pm b| \leq |a|+|b|\\)

### 比例与百分比

- **等比定理**：若 \\(\frac{a_1}{b_1}=\frac{a_2}{b_2}=...=\frac{a_n}{b_n}=k\\)，则分子分母分别相加比值仍为 \\(k\\)
- 增长率 = (现 - 原) / 原 × 100%
- 占比例 = 部分 / 总量 × 100%

## 二、代数式与函数

### 因式分解公式

| 公式 | 展开 |
|------|------|
| 平方差 | \\(a^2-b^2=(a+b)(a-b)\\) |
| 完全平方 | \\((a \pm b)^2 = a^2 \pm 2ab + b^2\\) |
| 完全立方 | \\((a \pm b)^3 = a^3 \pm 3a^2b + 3ab^2 \pm b^3\\) |
| 立方和/差 | \\(a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)\\) |
| 三元平方 | \\((a+b+c)^2 = a^2+b^2+c^2+2ab+2bc+2ca\\) |

## 三、方程与不等式

### 一元二次方程

标准形式：\\(ax^2+bx+c=0 \ (a \neq 0)\\)

| 工具 | 公式 |
|------|------|
| 判别式 | \\(\Delta = b^2-4ac\\) |
| 求根公式 | \\(x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}\\) |
| 韦达定理 | \\(x_1+x_2 = -\frac{b}{a}\\)，\\(x_1x_2 = \frac{c}{a}\\) |
| 两根差 | \\(|x_1-x_2| = \frac{\sqrt{\Delta}}{|a|}\\) |
| 平方和 | \\(x_1^2+x_2^2 = (x_1+x_2)^2 - 2x_1x_2\\) |

### 不等式

- **均值不等式**：\\(a+b \geq 2\sqrt{ab}\\)（一正二定三相等）
- **一元二次不等式**："大于取两端，小于取中间"
- 绝对值不等式：\\(|x| < a \iff -a < x < a\\)

## 四、数列

### 等差数列

| 公式 | 表达式 |
|------|--------|
| 通项 | \\(a_n = a_1 + (n-1)d\\) |
| 求和 | \\(S_n = \frac{n(a_1+a_n)}{2} = na_1 + \frac{n(n-1)}{2}d\\) |
| 等差中项 | \\(a,b,c\\)等差 \\(\Rightarrow 2b = a+c\\) |
| 等距取项 | 下标等差 ⇒ 项也等差 |

### 等比数列

| 公式 | 表达式 |
|------|--------|
| 通项 | \\(a_n = a_1 q^{n-1}\\) |
| 求和 | \\(S_n = \frac{a_1(1-q^n)}{1-q} \ (q \neq 1)\\) |
| 等比中项 | \\(a,b,c\\)等比 \\(\Rightarrow b^2 = ac\\) |

## 五、几何

### 平面几何

**三角形**
- 面积：\\(S = \frac{1}{2} \times \text{底} \times \text{高}\\)
- 等边：\\(S = \frac{\sqrt{3}}{4}a^2\\)
- 海伦公式：\\(S = \sqrt{p(p-a)(p-b)(p-c)}\\)，其中 \\(p = \frac{a+b+c}{2}\\)

**四边形**
- 梯形面积：\\(S = \frac{(a+b)h}{2}\\)
- 平行四边形：\\(S = \text{底} \times \text{高}\\)

**圆**
- 面积：\\(S = \pi r^2\\)，周长：\\(C = 2\pi r\\)
- 扇形弧长：\\(l = \frac{n\pi r}{180°}\\)，面积：\\(S = \frac{1}{2}lr = \frac{n\pi r^2}{360°}\\)

### 解析几何

| 公式 | 表达式 |
|------|--------|
| 两点距离 | \\(|AB| = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}\\) |
| 点到直线 | \\(d = \frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}\\) |
| 圆标准 | \\((x-x_0)^2 + (y-y_0)^2 = r^2\\) |
| 中点坐标 | \\(( \frac{x_1+x_2}{2}, \frac{y_1+y_2}{2} )\\) |

### 立体几何

- 长方体体积：\\(V = abc\\)
- 柱体体积：\\(V = Sh\\)
- 锥体体积：\\(V = \frac{1}{3}Sh\\)
- 球体体积：\\(V = \frac{4}{3}\pi r^3\\)，表面积：\\(S = 4\pi r^2\\)

## 六、数据分析

### 排列组合

| 公式 | 表达式 |
|------|--------|
| 排列 | \\(A_n^m = \frac{n!}{(n-m)!}\\) |
| 组合 | \\(C_n^m = \frac{A_n^m}{m!} = \frac{n!}{m!(n-m)!}\\) |
| 性质 | \\(C_n^m = C_n^{n-m}\\)，\\(C_n^0 = 1\\) |

**常见方法**：
- **捆绑法**：相邻元素先打包再排列
- **插空法**：不相邻元素先排其他再插空
- **排除法**：总排列数 - 不满足条件的排列数

### 概率

**古典概型**：\\(P(A) = \frac{\text{事件A包含的基本事件数}}{\text{总基本事件数}}\\)

**加法公式**：\\(P(A+B) = P(A) + P(B) - P(AB)\\)

**伯努利概型**（独立重复试验）：\\(P_n(k) = C_n^k p^k (1-p)^{n-k}\\)

## 七、应用题

| 题型 | 关键公式 |
|------|---------|
| **利润问题** | 利润=售价-进价；利润率=利润/进价×100% |
| **行程-相遇** | \\((v_1+v_2)t = s\\) |
| **行程-追及** | \\((v_1-v_2)t = s\\)（同向而行） |
| **行船问题** | 顺水速=船速+水速；逆水速=船速-水速 |
| **工程问题** | 工效=1/时间；合作总工效=各工效之和 |
| **浓度问题** | 浓度=溶质/溶液×100%；溶质=浓度×溶液 |
| **容斥-两者** | \\(A \cup B = A + B - A \cap B\\) |
| **植树-线段** | 两端都种：棵数=总长/间距+1 |
| **植树-环形** | 棵数=总长/间距 |

## 八、条件充分性判断（专项）

**题目形式**：题干 + 条件（1）（2），判断哪个条件能推出结论。

**选项规则**：
| 选项 | 含义 |
|------|------|
| A | (1)充分，(2)不充分 |
| B | (2)充分，(1)不充分 |
| C | (1)(2)单独不充分，联合充分 |
| D | (1)充分，(2)也充分 |
| E | (1)(2)单独不充分，联合也不充分 |

**解题策略**：
1. 先判断条件（1）是否充分
2. 再判断条件（2）是否充分
3. 都不充分再考虑联合
4. **特值法**：代入特殊值验证边界情况
